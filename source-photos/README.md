# Originalfotos

Unbearbeitete Originale der Fotos von der früheren Wix-Website (volle Auflösung), gesichert am 9. Oktober 2026.
Die Website selbst nutzt verkleinerte Varianten (800 px und 1600 px) unter `assets/img/`.
Neue Fotos bitte ebenfalls hier ablegen und für die Website mit `sips -Z 1600` bzw. `sips -Z 800` verkleinern.
